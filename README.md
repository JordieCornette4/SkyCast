🚀 Installation

Clone the repository:

git clone https://github.com/JordieCornette4/SkyCast.git

Move into the project folder:

cd SkyCast

Install the required packages:

pip install -r requirements.txt

Start the application:

python app.py

Open your browser:

http://127.0.0.1:5000

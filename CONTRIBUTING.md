Contributing to SkyCast

Thank you for contributing to SkyCast!

Project Rules

1. Replace complete files instead of editing existing files.
2. Keep source files focused on a single responsibility.
3. Test every change before committing.
4. Write clear Git commit messages.
5. Keep the project beginner-friendly.
6. Tag every stable release with a version number.

Versioning

SkyCast follows semantic versioning:

- Major: "2.0.0"
- Minor: "1.2.0"
- Patch: "1.2.1"

Development Workflow

1. Replace one complete file.
2. Test the application.
3. Commit your changes.
4. Push to GitHub.
5. Continue with the next file.
